คู่มือ APTV ฉบับใช้งานจริง

APTV เป็นแอปเล่น IPTV (ไฟล์ m3u / txt, Xtream Codes, Stalker Portal) บนอุปกรณ์ Apple ทุกเครื่อง หน้านี้สรุปจาก คู่มือทางการ (ภาษาจีน) พร้อมภาพหน้าจอจริง ชื่อเมนูอ้างอิงแอปที่ตั้งภาษาเป็น English

ทุกแพลตฟอร์มใช้เหมือนกัน iOS, tvOS (Apple TV) และ macOS มีขั้นตอนการใช้งานเหมือนกันทุกอย่าง เรียนรู้ครั้งเดียวใช้ได้ทุกเครื่อง

01เริ่มต้นใช้งาน

หลักการคือ “เพิ่ม Config → แตะเลือกใช้งาน → ไปหน้า Channel”

  1. แตะแท็บ Config ที่แถบด้านล่างเข้าสู่ Config Center
  2. แตะไอคอนโซ่ + มุมขวาบนจะมีเมนู Add config ให้เลือกประเภท
  3. เลือก Subscribe แล้ววางลิงก์ m3u/txt → แตะ 保存 (บันทึก) มุมขวาบนอยากลองก่อน ใช้ลิงก์สาธิต https://pastebin.com/raw/40MQLfcA (ไม่มีช่องจริง ใช้ฝึกเท่านั้น)
  4. แตะวงกลมด้านขวาของ Config ที่เพิ่งเพิ่มให้ขึ้นเครื่องหมายถูก = Config ที่กำลังใช้งานอยู่ (เพิ่มแล้วไม่แตะ จะไม่มีช่องขึ้น)
  5. แตะแท็บ Channel แล้วแตะช่องเพื่อเล่นการ์ดช่องจะมีภาพพรีวิวและค่า Delay (ms) — ตัวเลขยิ่งน้อยยิ่งดี
ห้ามลืม: เปิด iCloud Sync ตั้งแต่วันแรก ค่าเริ่มต้นปิดอยู่ ถ้าไม่เปิด แล้วลบ/ติดตั้งแอปใหม่ Config ทั้งหมดจะหายและกู้คืนไม่ได้ — ดู หัวข้อ iCloud

02ประเภท Config เลือกแบบไหนดี

เมนู Add config มี 6 แบบ เลือกตามสิ่งที่ผู้ให้บริการให้มา

Subscribe

วางลิงก์ m3u หรือ txt อัปเดตตามต้นทางได้อัตโนมัติ

ใช้เมื่อ: ได้ลิงก์ playlist มา (พบบ่อยที่สุด)

Local

เลือกไฟล์ m3u/txt จากเครื่องหรือ iCloud Drive หรือกด “แชร์ → เปิดด้วย APTV” จากแอปอื่น

ใช้เมื่อ: มีไฟล์ playlist อยู่แล้ว

Blank

Config เปล่า ไว้เพิ่มช่องเองทีละช่อง

ใช้เมื่อ: มีแค่ลิงก์สตรีม (m3u8) — ดู หัวข้อ 03

Merging Config

รวมหลาย Config เป็นอันเดียว ช่องชื่อเดียวกันจะรวมกันและสลับแหล่งสำรองเอง

ใช้เมื่อ: มีหลายแหล่ง อยากได้ช่องที่ไม่ค่อยดับ

Xtream Codes

กรอก Server URL, Username, Password ที่ผู้ให้บริการ IPTV ให้มา

ใช้เมื่อ: ได้ข้อมูลล็อกอินแบบ Xtream

Stalker Portal

กรอก Portal URL และ MAC Address

ใช้เมื่อ: ผู้ให้บริการให้เป็นแบบ MAG/Portal

เพิ่มไฟล์ Local แล้วไม่ขึ้นในรายการ? ปัดปิดแอป (ปัดขึ้นจาก App Switcher) แล้วเปิดใหม่

03เพิ่มช่องเดี่ยวจากลิงก์ m3u8

มีแค่ลิงก์สตรีมช่องเดียว ใช้ Config แบบ Blank

  1. Config → ปุ่มโซ่ + → Blankใส่ชื่อ Config (ไม่ใส่ก็ได้ จะชื่อ Default) แล้วแตะ 保存
  2. แตะวงกลมขวามือให้ Config นี้ถูกเลือก
  3. ไปแท็บ Channel → แตะ 添加单频道 (Add single channel)หรือ 添加多频道 = เพิ่มหลายช่อง, 添加融合频道 = ช่องรวมหลายแหล่ง
  4. กรอก Channel URL และ Channel Name → 保存รองรับ HTTP, RTP, RTSP, RTMP ส่วนช่องอื่นไม่ต้องกรอก
  5. แตะช่องเพื่อเล่น
ช่องในฟอร์มใช้ทำอะไร
Channel URL *ลิงก์สตรีม (จำเป็น)
Channel Name / Logoชื่อและโลโก้ช่อง (ไม่ใส่ก็ได้)
EPG ID / EPG Nameค่า tvg-id / tvg-name สำหรับจับคู่ผังรายการ
Request Parametersใส่ Header เช่น User-Agent, Referer สำหรับลิงก์ที่ต้องใช้
catchupdefault / append สำหรับดูย้อนหลัง — ดู หัวข้อ 07
แค่อยากลองเปิดลิงก์ ไม่ต้องบันทึก ใช้ปุ่ม ▶ มุมขวาบนหน้า Channel = Quick Play → Network Playback วาง URL แล้วเล่นทันที (มี Local Playback และ Browser ด้วย)

04ช่องต่าง ๆ ในฟอร์ม Subscribe

กรอกแค่ลิงก์ก็ใช้ได้ ที่เหลือเป็นตัวเลือกเสริม

05Merging Config: รวมหลายแหล่งให้ช่องไม่ดับ

  1. Config → ปุ่มโซ่ + → Merging Config
  2. เลือก Config ที่จะรวมอย่างน้อย 1 อันลำดับที่แตะเลือก = ลำดับความสำคัญ (แหล่งแรกเล่นก่อน)
  3. ดูรายการช่องมุมขวาบนของช่องบอกจำนวนแหล่งสำรอง
  4. เล่นช่องแหล่งปัจจุบันเล่นไม่ได้ จะสลับไปแหล่งถัดไปเอง
ปรับเวลารอก่อนสลับแหล่ง ค่าเริ่มต้น 5 วินาที ปรับที่ Setting›Advanced›Merging Config›Play Timeout

เคล็ดลับ: ชื่อช่องต้องตรงกันทุกตัวอักษรถึงจะรวมกัน ถ้าแหล่งหนึ่งชื่อ Thai PBS อีกแหล่งชื่อ ThaiPBS HD จะไม่ถูกรวม

07ดูย้อนหลัง (Catch-up)

สำหรับคนที่แก้ไฟล์ m3u เอง — ผู้ใช้ทั่วไปข้ามได้ ถ้าผู้ให้บริการตั้งไว้ให้แล้ว

อัตโนมัติ (ไม่ต้องตั้งค่า)

ถ้าลิงก์ช่องมีคำว่า PLTV หรือ TVOD APTV จะต่อพารามิเตอร์นี้ให้เอง

?playseek=${(b)yyyyMMddHHmmss}-${(e)yyyyMMddHHmmss}

ตั้งค่าทั้งไฟล์

ใส่ในบรรทัด #EXTM3U บนสุด ใช้กับทุกช่อง

#EXTM3U catchup="append" catchup-source="?playbackbegin=${(b)yyyyMMddHHmmss}&playbackend=${(e)yyyyMMddHHmmss}"

ตั้งค่าเฉพาะช่อง (ต่อท้ายลิงก์เดิม)

#EXTINF:-1 catchup="append" catchup-source="?playseek=${(b)yyyyMMddHHmmss}-${(e)yyyyMMddHHmmss}",CCTV1
http://hostname:port/xxx

ตั้งลิงก์ย้อนหลังแยกต่างหาก

ใช้ catchup="default" แล้วใส่ลิงก์เต็มของเซิร์ฟเวอร์ย้อนหลัง

#EXTINF:-1 catchup="default" catchup-source="http://hostname:port/xxx2?playseek=${(b)yyyyMMddHHmmss}-${(e)yyyyMMddHHmmss}",CCTV1
http://hostname:port/xxx

ใช้เวลาแบบ UTC

#EXTINF:-1 catchup="append" catchup-source="?playseek=${(b)yyyyMMddHHmmss:utc}-${(e)yyyyMMddHHmmss:utc}",CCTV1
http://hostname:port/xxx

หรือรูปแบบสั้น

#EXTINF:-1 catchup="append" catchup-source="?playseek={utc:YmdHMS}-{utcend:YmdHMS}",CCTV1
http://hostname:port/xxx

ใช้ Timestamp

#EXTM3U catchup="append" catchup-source="?starttime=${(b)timestamp}&endtime=${(e)timestamp}"
http://hostname:port/xxx
ตัวแปรความหมาย
${(b)…} / ${(e)…}เวลาเริ่ม / เวลาจบ ของรายการที่เลือก
yyyyMMddHHmmssรูปแบบวันเวลา เช่น 20261003203000
:utcแปลงเป็นเวลา UTC (ไทย = UTC+7)
timestampUnix timestamp (วินาที)
append / defaultต่อท้ายลิงก์ช่องเดิม / ใช้ลิงก์ที่กำหนดแทนทั้งหมด

ถ้าผู้ให้บริการต้องการเปลี่ยน PLTV เป็น TVOD ในลิงก์ย้อนหลัง เปิดได้ที่ Advanced›Laboratory›Replace PLTV with TVOD

08iCloud Sync & Apple TV

เปิด iCloud Sync (ต้องทำ 2 ที่)

  1. ในแอป: Setting›iCloud›iCloud Sync เปิดสวิตช์iCloud Status ต้องเปลี่ยนจาก Disabled เป็นเปิดใช้งาน และกด Manual Sync เพื่อ sync ทันที
  2. ใน iPhone: Settings›[ชื่อคุณ]›iCloudเปิดทั้ง APTV และ iCloud Drive
ทำไม Config หายหมด? ถ้าออกจาก iCloud, สลับบัญชี หรือปิด iCloud ของแอป Apple จะล้างข้อมูลในเครื่อง แต่ข้อมูลบนคลาวด์ยังอยู่ — เปิด iCloud กลับมาแล้วจะ sync คืน ส่วนถ้าไม่เคยเปิด sync เลย การลบแอปจะทำให้ข้อมูลหายถาวร

เช็กลิสต์: sync ข้ามเครื่องไม่ได้

ต้องเป็น APTV Pro และกด “กู้คืนการซื้อ” ในทุกเครื่องแล้ว จากนั้นไล่เช็ก:

  • ทุกเครื่องล็อกอิน Apple ID / iCloud เดียวกัน
  • เปิด iCloud ของ APTV และ iCloud Drive แล้ว
  • ในแอป Setting›iCloud Status ไม่ใช่ Disabled ทุกเครื่อง
  • พื้นที่ iCloud ยังไม่เต็ม
  • Apple TV: ตั้ง “ผู้ใช้เริ่มต้น” (Default User) ถูกบัญชีแล้ว — สาเหตุอันดับ 1 (ประมาณ 99%) ของการ sync ไม่ได้
  • Apple TV: ลองออกจากระบบ iCloud แล้วเข้าใหม่
  • Apple TV: ถอดปลั๊กไฟแล้วเสียบใหม่ (ไม่ใช่แค่ Restart จากเมนู)

ตั้งผู้ใช้เริ่มต้นบน Apple TV

การ “สลับผู้ใช้ปัจจุบัน” ไม่ใช่ การตั้งผู้ใช้เริ่มต้น ต้องไปตั้งที่

Settings›Users and Accounts›Default User

09กู้คืนการซื้อ (Restore Purchase) ไม่ได้

แตะหัวข้อที่ตรงกับข้อความ error ที่เห็น

ไม่พบหลักฐานการซื้อ未获取到您的购买凭据

1. ล็อกอินผิดบัญชี — บัญชีที่ใช้กู้คืนต้องเป็นบัญชีที่ซื้อ (มักเกิดกับคนมีหลายบัญชีหลายประเทศ) ดูราคาในหน้าซื้อช่วยเดาได้ว่าเป็นบัญชีประเทศไหน ตรวจประวัติการซื้อได้ที่ reportaproblem.apple.com

2. บัญชีที่ดาวน์โหลดกับบัญชีที่ซื้อไม่ตรงกัน — Apple กำหนดให้ต้องเป็นบัญชีเดียวกัน แก้โดยลบแอป → ล็อกอินบัญชีที่ซื้อ → ดาวน์โหลดใหม่ → กู้คืน (ข้อนี้ไม่ใช้กับ Apple TV ซึ่งต่างบัญชีได้)

3. มีประวัติซื้อแต่ไม่มีประวัติดาวน์โหลด — เช่น ดาวน์โหลดด้วยบัญชี A แต่ซื้อด้วยบัญชี B ให้ลบแอปแล้วดาวน์โหลดใหม่ด้วยบัญชี B

4. ซื้อแบบเก่า (ก่อน 1 ต.ค. 2022) — ตอนนั้นเป็นแอปเสียเงินก่อนดาวน์โหลด ให้ไปที่ Setting›About APTV›RCID เลือกสร้างใหม่ รอสักครู่แล้วกู้คืน ถ้ายังไม่ได้ให้สร้างใหม่อีกหลายครั้ง

คำขอไม่น่าเชื่อถือ (MitM)无法信任的请求

แอป Proxy/VPN ของคุณกำลัง MitM โดเมน api.revenuecat.com (มักเกิดจากสคริปต์ปลดล็อก) แก้ได้ 2 ทาง:

  • ยกเว้นโดเมนนี้ใน MitM เช่น Quantumult X ใส่ -api.revenuecat.com ในรายการ hostname
  • หรือปิด Proxy → เปิด APTV ให้กู้คืนเอง → แล้วค่อยเปิด Proxy กลับ
Alias limit reached (พบบ่อยมาก)Error creating subscriber alias. Alias limit reached.

แปลว่าเคยใช้ บัญชีแชร์ ดาวน์โหลด/กู้คืนแอป แล้วบัญชีนั้นถูกแบนเพราะกู้คืนบ่อยเกินไป

แก้: Setting›About APTV›RCID → สร้าง RCID ใหม่ → รอสักครู่แล้วกู้คืน ถ้ายังไม่ได้ให้ทำซ้ำ

เกิดข้อผิดพลาดเครือข่าย / SSLA network error has occurred.

ปัญหาเน็ต — ถ้าเปิด VPN อยู่ให้ปิด ถ้าไม่ได้เปิดลองเปิดดู หรือรีสตาร์ตเครื่อง

RCID อยู่ที่ไหน ในแอป APTV (ไม่ใช่การตั้งค่าของ iPhone): Setting›About APTV เลื่อนลงไปที่ส่วน Contact แล้วแตะแถว RCID

10ดูช่อง IPv6

ช่อง IPv6 มักเร็ว ชัด และเสถียรกว่า เพราะคนใช้น้อย เน็ตมือถือส่วนใหญ่รองรับอยู่แล้ว ปัญหามักอยู่ที่เน็ตบ้าน

รู้ได้ไงว่าเป็นช่อง IPv6

APTV แสดงป้าย IPv6 ที่มุมซ้ายล่างของช่อง (ปิดได้ที่ Setting › Show IPV6 ID)

เช็กว่าเน็ตรองรับไหม

  • เข้า test-ipv6.com (ปิด Proxy/VPN ก่อนทดสอบ)
  • ท้ายสุดของหน้า Setting จะเขียน Current network type: IPv4 / IPv6 (แตะเพื่อตรวจใหม่ ควรปิด VPN ก่อน)
  • วิธีง่ายสุด: ลองเล่นช่อง IPv6 — เล่นได้คือรองรับ

เปิด IPv6 ที่บ้าน

  1. เปิด IPv6 ในเราเตอร์ส่วนใหญ่ปิดไว้ตั้งแต่โรงงาน เข้าหน้าแอดมินเราเตอร์ หาเมนู IPv6 แล้วเปิด — ถ้าเราเตอร์เป็นตัวต่อ PPPoE เลือกโหมด Native, ถ้า ONU/โมเด็มไฟเบอร์เป็นตัวต่อ ให้เราเตอร์ใช้โหมด NAT6
  2. ถ้ายังไม่ได้ IPv6 → เปิดที่ ONU/โมเด็มไฟเบอร์ตั้งโหมด IP เป็น “IPv4 & IPv6” บางรุ่นต้องใช้รหัสผู้ดูแลระดับสูง (ไม่ใช่รหัสหลังเครื่อง) ขอได้จากฝ่ายบริการลูกค้าของผู้ให้บริการเน็ต
  3. เปิด IPv6 ในแอป Proxy (ถ้าใช้)ส่วนใหญ่ปิด IPv6 ไว้ เช่น Quantumult X ต้องเปิด “Compatibility Enhancement” ในการตั้งค่าอื่น ๆ
เคยดูได้ แต่จู่ ๆ ดูไม่ได้ รีสตาร์ตเราเตอร์หรือโทรศัพท์ และตรวจว่าแอป Proxy ไม่ได้ปิด IPv6

11คำถามที่พบบ่อย

m3u กับ m3u8 ต่างกันยังไง

ให้นึกถึง “ห้องเรียนกับนักเรียน” — m3u คือรายการหลายช่องรวมกัน (playlist) ส่วน m3u8 โดยทั่วไปคือลิงก์สตรีมของช่องเดียว ใช้ Subscribe กับ m3u และใช้ Blank + เพิ่มช่อง กับ m3u8 (หัวข้อ 03)

ช่องเปิดไม่ขึ้น / หมุนค้าง
  • ดูค่า Delay บนการ์ดช่อง ถ้าไม่มีตัวเลขหรือสูงมาก แปลว่าแหล่งต้นทางมีปัญหา
  • ลองเปลี่ยน Setting › Preferred Player
  • ลิงก์ที่ต้องใช้ Header ให้ใส่ใน Request Parameters ของช่อง
  • ใช้ Merging Config รวมหลายแหล่ง เพื่อให้สลับแหล่งสำรองอัตโนมัติ
ส่งไปเล่นใน VLC / Infuse หรือขึ้นทีวีได้ไหม

ได้ มีตัวเลือกส่งช่องไปเล่นใน VLC หรือ Infuse และในหน้าเล่นมีปุ่ม AirPlay (ไอคอนจอ) ส่งขึ้น Apple TV / ทีวีที่รองรับ

เพิ่มช่องเข้ารายการโปรดยังไง

แตะ ♡ มุมขวาบนในหน้าเล่น แล้วดูได้ที่แท็บ Favorite

12เปิด YouTube และเว็บวิดีโอด้วย Browser ในแอป

APTV มีเบราว์เซอร์ในตัว เปิดเว็บวิดีโอ (YouTube, Netflix, TikTok, Bilibili ฯลฯ) ได้จากในแอป

  1. แท็บ Channel → ปุ่ม ▶ มุมขวาบน (Quick Play) → Browserหน้าแรกมีทางลัด Video Websites (กดค้างเพื่อจัดลำดับ) และ Favorite channels (บุ๊กมาร์ก)
  2. แตะ YouTube หรือพิมพ์ URL / คำค้นในช่องด้านล่างล็อกอินบัญชี Google ในนี้ได้เหมือนเว็บทั่วไป
  3. เปิดคลิปแล้วดูบนหน้าเว็บได้เลย
  4. ปุ่ม ▶ ข้างช่อง URL = Video Sourcesแอปจะค้นหาลิงก์วิดีโอในหน้านั้น (ตัวเลขแดงคือจำนวนที่เจอ) ถ้าได้ลิงก์ จะเปิดด้วยเครื่องเล่นของ APTV ได้
  5. ปุ่ม ⋯ = เมนู MoreBookmark This Page, Mobile Website, Website Media Compatibility, Page Zoom, Fullscreen Webpage, History และ Clear History and Website Data (จะออกจากระบบทุกเว็บ แต่เก็บบุ๊กมาร์กไว้)
YouTube ส่งเข้าเครื่องเล่น APTV ไม่ได้ ทดสอบแล้ว Video Sources เจอคลิป แต่ขึ้นว่า YouTube ไม่ให้ลิงก์สำหรับเล่นแยก (does not expose a playback URL) ต้องดูบนหน้าเว็บเท่านั้น ฟีเจอร์ส่งเข้าเครื่องเล่นจึงใช้ได้กับเว็บที่เปิดลิงก์ m3u8/mp4 ตรง ๆ
คลิปเล่นไม่ได้ หรือภาพเต็มจอไม่ได้ ลอง ⋯ → Website Media Compatibility หรือ Fullscreen Webpage ส่วนเว็บที่ใช้บ่อยให้กด ⋯ → Bookmark This Page จะขึ้นในหน้าแรก Browser
