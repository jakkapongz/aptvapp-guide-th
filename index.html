How To Start?

เริ่มดูช่องแรกใน 5 ขั้น — iPhone, iPad, Apple TV, Mac ขั้นตอนเหมือนกัน

  1. แตะแท็บ Config ที่แถบด้านล่างเข้าสู่ Config Center
  2. แตะไอคอนโซ่ + มุมขวาบนเมนู Add config จะขึ้นมา
  3. เลือก Subscribe วางลิงก์ m3u/txt → แตะ 保存 (Save)ลองด้วยลิงก์สาธิต https://pastebin.com/raw/40MQLfcA ได้ (ไม่มีช่องจริง)
  4. แตะวงกลมขวามือของ Config ที่เพิ่มให้ขึ้นเครื่องหมายถูก = ใช้งานอยู่ ถ้าไม่แตะจะไม่มีช่องขึ้น
  5. กลับแท็บ Channel แตะช่องเพื่อเล่น
เปิด iCloud Sync ตั้งแต่วันแรกค่าเริ่มต้นปิดอยู่ ถ้าลบแอปตอนยังไม่เปิด Config จะหายถาวร → Setting › iCloud

เพิ่มช่องเดี่ยว (m3u8)

มีแค่ลิงก์สตรีมช่องเดียว ใช้ Config แบบ Blank

  1. Config → + → Blank → 保存ชื่อไม่ใส่ก็ได้ (จะชื่อ Default)
  2. แตะวงกลมขวามือให้ Config นี้ถูกเลือก
  3. แท็บ Channel → 添加单频道添加多频道 = หลายช่อง · 添加融合频道 = ช่องรวมหลายแหล่ง
  4. ใส่ Channel URL + Channel Name → 保存รองรับ HTTP, RTP, RTSP, RTMP

Browser / YouTube

เปิดเว็บวิดีโอ (YouTube, Netflix, TikTok, Bilibili…) ในแอป

  1. Channel → ▶ → Browserหน้าแรกมี Video Websites (กดค้างเพื่อจัดลำดับ) และ Favorite channels
  2. แตะ YouTube หรือพิมพ์ URL ในช่องด้านล่างล็อกอิน Google ได้เหมือนเว็บปกติ
  3. ปุ่ม ▶ ข้างช่อง URL = Video Sourcesค้นหาลิงก์วิดีโอในหน้า ถ้าเจอจะเปิดด้วยเครื่องเล่น APTV ได้
  4. ปุ่ม ⋯ = เมนู MoreBookmark, Mobile Website, Media Compatibility, Page Zoom, Fullscreen, History
YouTube ส่งเข้าเครื่องเล่น APTV ไม่ได้ทดสอบแล้ว Video Sources เจอคลิป แต่ YouTube ไม่ให้ลิงก์เล่นแยก ต้องดูบนหน้าเว็บ ฟีเจอร์นี้ใช้ได้กับเว็บที่มีลิงก์ m3u8/mp4 ตรง
คลิปเล่นไม่ได้ / เต็มจอไม่ได้⋯ → Website Media Compatibility หรือ Fullscreen Webpage · เว็บที่ใช้บ่อย ⋯ → Bookmark This Page

⋯ → Clear History and Website Data จะออกจากระบบทุกเว็บ แต่เก็บบุ๊กมาร์กไว้

Config›🔗+›Merging Config

Merging Config

รวมหลาย Config เป็นอันเดียว ช่องชื่อเดียวกันกลายเป็นช่องเดียวที่มีหลายแหล่ง

  1. Config → 🔗+ → Merging Config
  2. เลือก Config ที่จะรวมอย่างน้อย 1 อันลำดับที่แตะ = ลำดับความสำคัญ (แหล่งแรกเล่นก่อน)
  3. ดูรายการช่องมุมขวาบนของช่องบอกจำนวนแหล่งสำรอง
  4. เล่นแหล่งปัจจุบันเล่นไม่ได้ จะสลับไปแหล่งถัดไปเอง
ปรับเวลารอก่อนสลับ (ค่าเริ่มต้น 5 วินาที)Setting›Advanced›Merging Config›Play Timeout

ชื่อช่องต้องตรงกันทุกตัวอักษร: Thai PBS กับ ThaiPBS HD จะไม่รวมกัน

Config›🔗+›Xtream Codes / Stalker Portal

Xtream / Stalker

Config›ไฟล์ m3u

ดูย้อนหลัง

สำหรับคนแก้ไฟล์ m3u เอง — ถ้าผู้ให้บริการตั้งให้แล้วข้ามได้ ดูย้อนหลังได้จากแท็บ Program ในหน้าเล่น

อัตโนมัติ

ลิงก์ช่องมี PLTV หรือ TVOD แอปจะต่อพารามิเตอร์นี้ให้เอง

?playseek=${(b)yyyyMMddHHmmss}-${(e)yyyyMMddHHmmss}

ทั้งไฟล์ (บรรทัด #EXTM3U)

#EXTM3U catchup="append" catchup-source="?playbackbegin=${(b)yyyyMMddHHmmss}&playbackend=${(e)yyyyMMddHHmmss}"

เฉพาะช่อง (ต่อท้ายลิงก์เดิม)

#EXTINF:-1 catchup="append" catchup-source="?playseek=${(b)yyyyMMddHHmmss}-${(e)yyyyMMddHHmmss}",CCTV1
http://hostname:port/xxx

ลิงก์ย้อนหลังแยก

#EXTINF:-1 catchup="default" catchup-source="http://hostname:port/xxx2?playseek=${(b)yyyyMMddHHmmss}-${(e)yyyyMMddHHmmss}",CCTV1
http://hostname:port/xxx

เวลา UTC

#EXTINF:-1 catchup="append" catchup-source="?playseek=${(b)yyyyMMddHHmmss:utc}-${(e)yyyyMMddHHmmss:utc}",CCTV1
http://hostname:port/xxx
#EXTINF:-1 catchup="append" catchup-source="?playseek={utc:YmdHMS}-{utcend:YmdHMS}",CCTV1
http://hostname:port/xxx

Timestamp

#EXTM3U catchup="append" catchup-source="?starttime=${(b)timestamp}&endtime=${(e)timestamp}"
${(b)…} / ${(e)…}เวลาเริ่ม / จบของรายการ
yyyyMMddHHmmssเช่น 20261003203000
:utcเวลา UTC (ไทย = UTC+7)
timestampUnix timestamp (วินาที)
append / defaultต่อท้ายลิงก์เดิม / ใช้ลิงก์ที่กำหนดแทน

Setting›iCloud

iCloud Sync

ต้องเปิด 2 ที่

  1. ในแอป: Setting›iCloud Sync เปิดสวิตช์iCloud Status ต้องไม่ใช่ Disabled แล้วกด Manual Sync
  2. ใน iPhone: Settings›[ชื่อคุณ]›iCloudเปิด APTV และ iCloud Drive
Config หายหมด?ออกจาก iCloud / สลับบัญชี / ปิด iCloud ของแอป → Apple ล้างข้อมูลในเครื่อง แต่บนคลาวด์ยังอยู่ เปิดกลับแล้วจะ sync คืน · ถ้าไม่เคยเปิด sync เลย ลบแอปแล้วหายถาวร

Sync ข้ามเครื่องไม่ได้

  • เป็น APTV Pro และกดกู้คืนการซื้อทุกเครื่องแล้ว
  • ทุกเครื่องใช้ Apple ID เดียวกัน
  • iCloud Status ไม่ใช่ Disabled ทุกเครื่อง
  • พื้นที่ iCloud ไม่เต็ม
  • Apple TV: ตั้ง Default User ถูกบัญชี — สาเหตุ ~99%
  • Apple TV: ออกจาก iCloud แล้วเข้าใหม่
  • Apple TV: ถอดปลั๊กไฟแล้วเสียบใหม่
ตั้ง Default User บน Apple TVการสลับผู้ใช้ ≠ ผู้ใช้เริ่มต้น ไปที่ Settings›Users and Accounts›Default User
